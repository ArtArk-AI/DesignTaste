# Data release

`manifests/` identifies the public tasks. `briefs/` contains the task descriptions. `rubrics/` contains the English and Chinese scoring criteria. `annotations/` contains the frozen per-image scores. `results/` contains aggregate tables and the results workbook.

The [Hugging Face dataset](https://huggingface.co/datasets/ArtArk/DesignTaste) hosts 2,418 generated images, 403 briefs with official reference-image download links, and 2,821 rating records. Full image collections are not bundled in this Git repository. Award-winning originals remain on their source websites. Use task IDs and hashes to connect the files.
