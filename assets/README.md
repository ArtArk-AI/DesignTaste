The comparison gallery shows selected examples from the paper, not a random sample. Aggregate results are reported in the README and the released score tables. Score differences in the charts use a 100-point scale; positive values favor the model.

The compact comparison preview preserves all seven column headings and the full artwork rectangles from the source figure. Only the two selected rows are shown, with dataset labels and a thin separator added for the README.

## README wordmark

| File | Use | Size |
| --- | --- | --- |
| [wordmark-light.svg](wordmark-light.svg) | Header on a light background | 1600 x 300 |
| [wordmark-dark.svg](wordmark-dark.svg) | Header on a dark background | 1600 x 300 |

The wordmark is an original editorial identity for DesignTaste. `DesignTaste` is set as one continuous typographic form, with the warm `T` acting as a small visual pivot between the two evaluation sides. The paired teal and ochre registration lines echo the benchmark's reference-to-generation comparison without adding a separate icon. The lettering is embedded as vector paths, so both variants render without a font dependency. The SVGs have transparent backgrounds.
